# PDF and full-paper workflow

Run `python scripts/pdf_inventory.py INPUT.pdf --out work/paper-inventory` (requires PyMuPDF). This emits page images, extracted page text and candidate caption records with page numbers. Paths are relative to the skill directory. It intentionally does not locate figure boundaries or declare coverage. It may miss scanned text, unusual captions, captions in images, landscape layouts, or tables; it may also flag cross-references. OCR scanned pages using available tools and review every rendered page. Check the last pages, foldouts and user-provided supplements. Detect composite figures and label each panel, including multiple figures per page and figures spanning pages. Make crops from page renderings with enough resolution and label boundaries manually. Distinguish a caption from an in-text mention; include uncaptioned visual panels where relevant. Record unresolved ambiguities.

Create an inventory before generating artifacts, e.g. `inventory.json` as an array of records with `id`, `page`, `panels`, `type`, `caption`, `status`, `provenance`, `assumptions`, `outputs`, and `validation`. Use 1-based printed PDF page order and note any difference from printed page numbers. Record full-paper scope, included supplements and absent materials. An automated candidate list is a starting point only. Reconcile inventory against the rendered pages, captions and final output folders. Keep partial results when interrupted.
