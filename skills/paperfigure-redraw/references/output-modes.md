# Output modes and verification

- **Quantitative charts:** save PNG and vector PDF or SVG; provide a runnable Python script and CSV/TSV/XLSX source data. Prefer supplied underlying data, then author data, then measured estimates from the visible plot. Preserve uncertainty, scales and missing data; do not infer raw distributions from summary charts. For each digitized series, document calibration points, axis scale, units, resolution and approximate accuracy. Use matplotlib or another appropriate library; only use synthetic data if the user explicitly requests a clearly labeled illustrative example.
- **Flowcharts and diagrams:** create PPTX with editable native shapes, text, connectors and arrowheads, including grouping and layering. Provide a preview image and generation script where practicable. A bitmap inside a slide is not an editable recreation. For complex scientific schematics, identify components that can only be approximated.
- **Tables:** create XLSX with editable cells, sensible data types, merged headers, number formats, borders and widths. Transcribe values exactly where legible; mark uncertain cells explicitly and explain them in a separate notes sheet. Do not replace formulas with invented formulas. Export a preview and provide source/transcription if useful.
- **Photos, maps, complex illustrations and hybrid panels:** reconstruct data-driven elements where evidence supports it. Preserve source images as labeled reference crops when necessary, and explicitly identify raster components. Never imply that an AI-generated biological image is experimental evidence.

Verify numerical values, legends, labels and scale against the source. Render generated charts, slides and sheets when tooling allows and visually inspect at publication size. Reopen PPTX and XLSX, inspect native object/cell structure and test editing when possible. Record which checks were actually performed; note font substitutions and differences. Include dependencies and a command to regenerate each output. Avoid relying solely on pixel similarity when line weights, fonts or anti-aliasing differ.
